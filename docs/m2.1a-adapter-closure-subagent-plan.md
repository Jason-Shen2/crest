# M2.1A Pi GUI Adapter Closure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace inferred standard-component handling with explicit runtime identity, public snapshots, concrete adapters, and adapter-owned tree traversal.

**Architecture:** Vendored standard components publish a `Symbol.for` kind marker and immutable semantic snapshots. `PiGuiAdapter` becomes the only standard-component serialization and dispatch boundary, while `walker.ts` keeps only adapter lookup, WeakMap-owned widget identity, Crest rich components, and unknown terminal fallback. `bridge.ts` uses adapter child discovery for nested target registration and limits method probing to terminal key input.

**Tech Stack:** TypeScript, vendored `pi-tui`, Electron main process, React widget schema, Vitest, Node.js 22

**Source Spec:** `docs/m2.1a-adapter-closure-spec.md`

**Commit Policy:** Do not commit. Every subagent leaves a focused working-tree diff for parent review.
