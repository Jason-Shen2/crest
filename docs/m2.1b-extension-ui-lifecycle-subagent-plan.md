# M2.1B Extension UI Lifecycle Closure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make extension UI state replayable from the session owner, terminate runtime-bound requests deterministically, preserve recoverable UI and compatible flags across reload, and use canonical session identity for every flag operation.

**Architecture:** `AgentSessionRuntime` owns an immutable `ExtensionUiSnapshot` beside transcript/turn state. The existing `session_state` IPC envelope carries that snapshot and the renderer replaces its mirror on replay. `/reload` moves a request-free `ExtensionReloadState` through a one-shot canonical-path map; interactive requests and live widget targets terminate with the old owner.

**Tech Stack:** TypeScript, Electron IPC, React hooks, Vitest, Node.js 22, Pi `AgentHarness`, Crest extension runtime

**Source Spec:** `docs/m2.1b-extension-ui-lifecycle-spec.md`

**Commit Policy:** Do not commit. Each subagent leaves a focused working-tree diff for the parent agent to review. The parent agent decides later whether and how to commit.

```ts
export interface ExtensionUiSnapshot {
    statuses: Record<string, string>;
    widgets: Record<string, string[]>;
    widgetnodes: Record<string, WidgetNode>;
    header?: WidgetNode;
    footer?: WidgetNode;
}

export interface ExtensionReloadState {
    ui: ExtensionUiSnapshot;
    flags: Record<string, boolean | string>;

function makeEmptyExtensionUiSnapshot(): ExtensionUiSnapshot {
    return { statuses: {}, widgets: {}, widgetnodes: {} };
}

function cloneExtensionUiSnapshot(snapshot: ExtensionUiSnapshot): ExtensionUiSnapshot {
    return {
        statuses: { ...snapshot.statuses },
        widgets: Object.fromEntries(Object.entries(snapshot.widgets).map(([key, lines]) => [key, [...lines]])),
        widgetnodes: { ...snapshot.widgetnodes },
        header: snapshot.header,
        footer: snapshot.footer,
    };
}
```

```ts
async function resolveCanonicalSessionOwner(
    sessionMetadata: unknown
): Promise<AgentSessionRuntime | undefined> {
    if (!isRecord(sessionMetadata)) return undefined;
    const rawPath = sessionMetadata.path;
    if (typeof rawPath !== "string" || rawPath.trim() === "") return undefined;
    const canonicalPath = await validateSessionPath(rawPath, "sessionMetadata.path");
    return sessionCache.get(canonicalPath);
}
```
